# Материалы для сдачи

Уточнения получены из скриншотов организаторов, переданных пользователем 29 сентября 2026.
Они описывают критерии конкурса; публикация и отправка заявки отдельно не выполнялись.

## Что должно быть доступно эксперту

- Репозиторий с README и локальным запуском; открытый просмотр или гостевой доступ.
- Архитектура, стек, API и инструкция развёртывания: ARCHITECTURE.md, MODELS.md,
  AUDIT.md, docs/openapi.json и README.md. Локальный Swagger находится на `/docs`.
- Полная презентация проекта в PDF с обязательными исходными слайдами 7–11 ЛЦТ.
  Дизайн, сетка и форматирование этих пяти слайдов сохраняются. Лишние карточки
  участников можно удалить. В предоставленном файле карточки находятся на исходном
  слайде 9, хотя сообщение организатора называет слайд 10; ориентируемся на содержание.
- Девять презентаций: три варианта на каждом из VK Tech, WorkSpace, Education.
- Видео: загрузка неизвестного шаблона, добавление материалов, получение трёх
  вариантов и текста выступления. Выданные шаблоны и шаблон ЛЦТ не заменяют неизвестный.
- Прототип либо допустимая для backend-задачи видеодемонстрация/Swagger.

Можно использовать одну ссылку в нескольких полях, если по ней легко найти все
соответствующие файлы. Внешние ссылки должны быть доступны проверяющему.

## Что подтверждают текущие материалы

Результаты и ограничения перечислены в verification.md. Демонстрация использует
явно обозначенный диагностический режим без LLM и синтетический контент.
Это не подтверждение качества AI-планирования, стоимости токенов или скорости VK API.
Публичная PPTX-фикстура взята из python-pptx под MIT; точный URL, версия и SHA-256
сохранены рядом с видео. Под неё не добавлялись отдельные правила оформления.

Текст выступления формируется вместе с вариантами из исходных фактов. Подготовка
шаблона измеряется отдельно. Пять минут относятся ко всем трём вариантам и тексту,
а не к одной презентации. На отборочном этапе живой питч не требуется.

## Фиксация версии

По сообщению организатора стоп-код — **29 сентября 2026, 23:59 МСК**.
До этого момента материалы и ссылки должны быть сохранены в личном кабинете.
После стоп-кода сданная ветка, файлы по сданным ссылкам и публичный стенд должны
оставаться неизменными. Локальные доработки или отдельная приватная ветка допустимы,
но не входят в оценку сданной версии.

Для локального пакета сохраняются контрольные суммы файлов и идентификатор версии.
Пакет остаётся черновиком до заполнения команды и прохождения внешних проверок.
Автоматическая отправка, изменение доступа, push, deployment и обновление опубликованных
материалов не входят в этот сценарий.
