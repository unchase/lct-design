# Проверки результата

Каждый finding содержит правило, статус, важность, класс, evidence, слайд/объект/рамку
и поддерживаемое исправление. `not_run` не равен `passed`. Отсутствие найденных ошибок
не гарантирует отсутствие всех ошибок дизайна.

| Проверка | Метод / предел |
|---|---|
| Связи PPTX | Детерминированная разрешимость package targets |
| Границы объектов | EMU-геометрия созданных содержательных объектов |
| Пересечения | Геометрия содержательных блоков; не декоративных фигур |
| Переполнение текста | Эвристика ширины символов, кегля и доступной высоты |
| Реальные границы | Poppler PDF word boxes относительно страницы |
| Сохранность текста | Сравнение токенов manifest и PDF; лигатуры/переносы могут дать предупреждения |
| Плотность | Пункты, слова, строки/колонки таблицы |
| Заполненность | Оценка площади текста и визуализаций: меньше 25% (кроме титула) или больше 75% слайда — предупреждение |
| Изображения шаблона | Содержательный блок пересекается с картинкой макета более чем на 10% — ошибка; такой выбор макета моделью отклоняется до вёрстки |
| Факты в сгенерированном тексте | При написании содержания по брифу пункт, таблица или график с числом, которого нет в брифе, удаляется; причина записывается в предупреждения |
| Пустота/дубли/заглушки | Текстовые правила |
| Контраст | Цвет текста против извлечённого фона; сложный фон требует просмотра |
| Типографика | Принадлежность к извлечённым шрифтам, доступность renderer fonts |
| Контекст | VLM по реальным PNG и исходным данным; offline → not_run |

Выбранный `refit` снижает размер текста в пределах читаемости и создаёт новую версию;
он не удаляет контент. Если текст всё ещё не помещается, finding остаётся. Сервис не
обещает автоматическое исправление всех типов замечаний. Родительский PPTX не меняется.

Шрифты оригинала могут отсутствовать в Linux. Подмена отмечается в отчёте; установка
брендовых файлов допустима только при наличии права на них. Стандартный renderer содержит
DejaVu и Liberation. Снимок — фактический LibreOffice render, а не эмуляция браузером.

Ограничения: нет обученного визуального детектора всех дефектов, доказательства
семантической точности модели или универсального layout solver. SmartArt-поддержка
описана в README; нативное распознавание отдельно от проверки ручного редактирования.
