# Модели и стоимость

По умолчанию режим без AI: внешних запросов нет. Он проверяет импорт, вёрстку,
экспорт и технический аудит; его нельзя выдавать за живой AI-пайплайн.

## Подключение

Страница «Настройки AI» поддерживает OpenRouter (`https://openrouter.ai/api/v1`)
и совместимый `/chat/completions` API, включая локальный. Список `/models` необязателен:
ID можно ввести вручную. Проверка соединения по отдельной кнопке делает небольшой
платный запрос JSON и, если включено, проверку изображения. JSON mode отключается
для серверов без `response_format`. Успешный тест не доказывает качество/скорость
полной генерации. После изменения настроек прежний тест не считается актуальным.

Настройки окружения перечислены в `.env.example`. Сохранённые в UI имеют приоритет.
Ключ хранится в `provider.private.json` в каталоге данных сервера (POSIX: 0600), без
шифрования диска; не входит в результаты, журнал задания или ответ настроек. Доступ
к диску и резервным копиям ограничивает оператор. При смене адреса старый ключ не
переносится. Сброс UI сохраняет пустые настройки, а не включает прежний ключ из
окружения. Изменение провайдера после постановки live-задания в очередь требует
новой генерации: старое задание не отправит материалы на новый адрес. Это правило
действует и для ручного ремонта.

Конкурсный режим по умолчанию требует для каждой используемой модели MIT либо
Apache-2.0, 0 < полное число параметров <=35B и ссылку на карточку. Это декларация
оператора, а не автоматическая проверка лицензии и весов. Для личного использования
других моделей режим можно явно отключить. По уточнению организатора контракт
inference OpenAI-compatible. `.env.example` содержит заготовку OpenRouter с моделью
из условий `qwen/qwen3.8-27b` (Apache-2.0, 27,8B, текст и изображения); ключ
оператор вводит сам. Для OpenRouter без ключа AI не считается настроенным.

## Контур генерации

До отсчёта готовится шаблон: OOXML, рендер и визуальные признаки. При включённой
VLM один запрос описывает до 72 композиций на контактных листах; результат кэшируется
по шаблону, ревизии настроек и промпту. Неполный охват указан в профиле. Время и usage
этой подготовки учитываются отдельно от генерации.

После подготовки общий бюджет составляет 300 секунд на все варианты:

0. Только для брифа без материалов — запрос написания содержания (`prompts/outline.md`):
   до 5000 выходных токенов, 90 секунд; числа проверяются по брифу программно.
1. Один LLM-запрос: порядок/группировка source IDs, реальные pattern IDs и слоты для
   всех вариантов. До 6000 выходных токенов, 75 секунд.
2. Сборка PPTX и рендер с остатком общего времени. Факты и заметки берутся из
   материалов; готовые материалы модель не переписывает.
3. При включённой VLM — один пакетный аудит: до 12 слайдов на вариант, 36 изображений
   суммарно, JPEG до 960x540, 5000 выходных токенов, 60 секунд. Для длинных презентаций
   слайды выбираются равномерно; охват показан явно.
4. При замечаниях и достаточном остатке — максимум один запрос ремонта композиции
   и слотов, 4000 токенов, 40 секунд. Повторный технический аудит проверяет результат;
   изменённые слайды не считаются проверенными прежним VLM-аудитом.

Промпты `src/lct_design/prompts/` задают правила ясности, иерархии,
читаемости, плотности и сохранения бренда. Неизвестные source IDs, пропуски, повторы,
чужие или пересекающиеся слоты отклоняются. Инструкции в материалах считаются данными.
Ошибка модели не включает скрытый offline-режим. Повторов при неверном JSON нет.

HTTP имеет общий таймер запроса, не только таймаут бездействия. Рендер получает
остаток бюджета. При истечении времени сохраняются готовые варианты с частичным
статусом. Синхронная сборка проверяет время между этапами; завершение текущей операции
и очистка могут занять дополнительное время. Это контроль бюджета, не подтверждённый
SLA. Замеры p95 на разрешённом inference, длинном контенте и ремонте ещё нужны.

## Расход и границы проверки

Для Qwen3 рассуждения отключаются (`LCT_DISABLE_REASONING`), иначе модель тратит лимит
токенов до ответа. Для OpenRouter запрос просит самых быстрых поставщиков
(`provider.sort=throughput`): время одной модели у разных хостов различается в разы.
Замер 29.09.2026, `qwen/qwen3.8-27b`, 12 слайдов × 3 варианта по брифу: 119 с, около $0,03.

Два (по брифу — три) штатных запроса генерации с VLM и не более одного для ремонта, плюс отдельная
подготовка шаблона и нажатия проверки соединения. Без VLM аудит помечается невыполненным.
`run.json` и интерфейс показывают вызовы, модели, полученный usage, охват и ремонт.
При сбое ответа usage неизвестен; сумма может быть меньше счёта провайдера. Стоимость
зависит от тарифа и image tokens. Материалы уходят только на выбранный сервер при
явном использовании AI.

Качество и время реального платного inference пока не измерены. Mock-тесты проверяют
протокол, ошибки и сохранение результатов, а не интеллект модели. Генерация изображений
моделью не реализована; входные изображения поддерживаются. Запуск: [QUICKSTART.md](QUICKSTART.md).
